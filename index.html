ⓘMengenal Linux

Apa itu Linux?

Linux adalah sistem operasi open source yang dikembangkan bersama oleh komunitas dari seluruh dunia. Linux dikenal fleksibel, stabil, aman, dan dapat digunakan pada komputer, server, hingga perangkat pintar.

◷Sejarah Singkat Linux

1983
Proyek GNU dimulai

Richard Stallman memulai proyek GNU untuk membangun sistem operasi bebas.

1991
Kernel Linux diperkenalkan

Linus Torvalds mengumumkan proyek kernel Linux yang kemudian berkembang bersama komunitas.

1992
Linux menggunakan lisensi GPL

Kernel Linux dirilis dengan lisensi GNU GPL sehingga dapat dikembangkan dan dibagikan secara terbuka.

Today
Digunakan di seluruh dunia

Linux hadir dalam berbagai distribusi dan digunakan pada server, desktop, cloud, serta perangkat lainnya.
